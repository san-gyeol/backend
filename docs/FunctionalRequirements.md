## 3. 기능 요구사항

- [ ] 사용자는 무등산의 날씨를 확인할 수 있다.
    - [ ] 홈 날씨는 무등산 주소지(북구 금곡동 산 1-1, 좌표 35.124386, 127.009131)를 기준으로 한다.
    - [ ] 코스 날씨는 해당 코스 거점 중 최고 고도 지점을 기준으로 한다.
    - [ ] 표시 항목: 온도, 체감온도, 강수확률, 강수량, 습도, 일출/일몰 시각, 출처(OpenWeather)
    - [ ] 강수 현상이 없을 때 강수량은 '없음'으로 구분해 표현한다. (0mm와 다름 — 화면 "-" 대응)
    - [ ] 화면에 보여줄 대표 강수확률을 정하는 규칙을 갖는다. (미결: 가까운 시점 기준 vs 당일 최대 기준)
    - [ ] 날씨를 가져오지 못하면 실패를 사용자에게 알리고, 사용자는 다시 시도할 수 있다. (통제정보 동일)
- [x] 사용자는 무등산의 실시간 통제정보를 확인할 수 있다. (GET /api/v1/controls — 2026-08-25 실서버 검증)
    - [x] 구역은 무등산, 무등산동부 2개로 구분한다.
    - [x] 통제 상태는 정상 / 부분통제 / 전면통제 3종으로 표현한다.
    - [x] 원천 데이터(공단)를 3종 상태로 판정하는 매핑 규칙을 갖는다. (스파이크로 확정 — 전면통제 문자열은 미실측, 관측 시 확인)
    - [x] 표시 항목: 구역, 통제 상태, 출처(국립공원공단) — 코드+한글 라벨 동시 제공
    - [x] 조회 실패 시 에러 응답을 내려주고, 사용자는 다시 시도할 수 있다. (502 + CONTROL502_001. 실패 경로 수동 검증은 캐시 작업 시 예정)
- [ ] 사용자는 무등산 국립공원의 코스를 확인할 수 있다.
    - [x] 코스는 이름, 거리, 소요시간, 난이도를 필드로 갖는다.
    - [x] 이름: 코스 이름은 비어 있을 수 없다.
    - [x] 거리: 거리 단위는 km로 0보다 커야 한다.
    - [x] 소요시간: 소요시간은 0보다 커야 한다.
    - [x] 난이도: EASY/NORMAL/HARD의 3가지 종류 ENUM으로 정의한다.
    - [ ] 코스 목록을 순서대로 제공한다. (Courses)
    - [ ] 실제 무등산 4개 코스 데이터를 등록한다.
- [ ] 사용자는 지도에서 거점을 확인할 수 있다.
- [ ] 사용자는 각 코스의 상세정보를 확인할 수 있다.

### 조사 메모

- **산악기상관측망**: 국립산림과학원이 전국 산악 관측소를 운영하며 공공데이터포털 Open API 제공.
  광주지방기상청에 무등산 산악기상 전용 페이지가 존재해 무등산 커버 유력. 지점 목록은 활용신청 후 확인.
- **통제정보**: 공공데이터포털에 개방된 것은 2021년 공지사항 CSV(정적)뿐.
  공단 통제 페이지는 구조화된 표(공원명 · 통제 상황 · 사유 · 기준 시간, "부분통제" 등 상태값)라 파싱 난이도는 낮은 편.
  공단 '탐방알리미' 앱이 실시간 통제를 표시하므로 내부 API 존재 가능성 있음 → 개발자도구 스파이크 예정.
- BFF 도입 근거였던 "통제정보 소스 불안정"이 이번 조사로 사실로 확인됨.
