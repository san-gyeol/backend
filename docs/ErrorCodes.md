# 에러 코드 명세서

> 모든 에러 응답은 `{"message": "...", "errorCode": "..."}` 형식.
> `message`는 사용자에게 그대로 보여줄 수 있는 문구, `errorCode`는 분기·로깅·문의용 식별자.

## 코드 형식

`{도메인}{HTTP상태}_{일련번호}` — 예: `CONTROL502_001`
- 도메인: `COMMON`(전역), `CONTROL`(통제정보), `WEATHER`(날씨), `COURSE`(코스)

## 코드 목록

| errorCode | HTTP | message | 발생 조건 | 프론트 권장 처리 |
|---|---|---|---|---|
| `COMMON400_001` | 400 | 요청 값이 올바르지 않습니다. | 경로 변수 타입 불일치 (예: courseId에 문자) | 요청 값 확인 (개발 중 오류 가능성) |
| `COMMON404_001` | 404 | 요청한 리소스를 찾을 수 없습니다. | 존재하지 않는 경로 호출 | 요청 URL 확인 (개발 중 오타 가능성) |
| `COURSE404_001` | 404 | 해당 코스를 찾을 수 없어요. | 등록되지 않은 courseId (1~4 외) | 코스 id 매핑 확인. 사용자에게는 message 그대로 표시 |
| `COMMON500_001` | 500 | 예기치 못한 예외가 발생했습니다. | 서버 내부 오류 | 에러 카드 + 다시 시도. 반복 시 백엔드에 문의 |
| `CONTROL502_001` | 502 | 통제정보를 불러오지 못했어요. 잠시 후 다시 시도해 주세요. | 공단 서버 응답 실패, 페이지 구조 변경으로 인한 수집 실패 | 통제 카드 영역에 에러 카드 + "다시 시도" 버튼 (디자인 정의 상태) |
| `WEATHER502_001` | 502 | 날씨 정보를 불러오지 못했어요. 잠시 후 다시 시도해 주세요. | OpenWeather 호출 실패(키 오류, 쿼터 초과, 타임아웃), 응답 구조 변경으로 인한 변환 실패 | 날씨 카드 영역에 에러 카드 + "다시 시도" 버튼 |

## 운영 메모 (백엔드용)

- `CONTROL502_001`이 반복 발생하면 공단 페이지 개편 가능성 — 서버 로그의 원인 예외
  ("알 수 없는 통제 상태: ...", "무등산 통제 행이 2건이 아닙니다: ..." 등)를 확인할 것
- `WEATHER502_001`은 서버 로그의 원인 예외 메시지로 구분한다.
  "OpenWeather 호출 실패: HTTP 401"은 API 키 누락이나 오류, "HTTP 429"는 무료 쿼터 초과,
  "OpenWeather 호출 실패: ResourceAccessException"은 타임아웃이나 네트워크 문제,
  "OpenWeather 응답에 ... 값이 없습니다"는 응답 구조 변경이다.
  원문 예외는 요청 URL에 API 키가 들어 있어 로그에 남기지 않는다 (게이트웨이에서 상태 코드만 남기고 떼어냄)
